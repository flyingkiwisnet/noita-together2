Setup & help

Install the companion and local mod

  1. Extract the complete beta archive. Keep the executable beside its bundled setup payload and notices.
  2. Run NoitaTogether2.exe. If WebView2 is missing, install Microsoft's Evergreen WebView2 Runtime, then reopen the app. No developer tools are required.
  3. Sign in with Twitch or Google. The app uses the public service by default; a remembered custom service remains your choice.
  4. Close Noita, then open Settings & help in the app. Under Noita installation, select Find Steam/GOG installations or Browse… to choose the folder containing noita.exe. Select Review mod installation / repair, check the destination, then select Install matching mod and confirm.
  5. In Noita's Mods menu, enable Noita Together 2 - Beta and turn on Allow unsafe mods, then restart Noita. Avoid enabling a duplicate legacy or Workshop copy.
  6. Choose a lobby in the app, start New Game in Noita, and let the host Start when everyone is ready.

Matching versions

Use the app's installation/verification result for your game build and matching mod. An incompatible game or app/mod version must be corrected before joining. The website manifest describes its release; the app still checks the service and actual installed files.

For updates, close the companion and Noita, extract the new archive, then reopen the app. Open Settings & help → Noita installation, select Review mod installation / repair, check the destination, then select Install matching mod and confirm. Keep your Windows user profile: credentials, identity and saved-world associations belong to your user data, rather than the extracted app folder. Do not delete saves to resolve a version error.

Local installation and GOG

The beta includes its local mod payload, so a separate mod download or Workshop subscription is unnecessary. Browse is available when automatic discovery misses a custom Steam library or GOG folder. Native DLLs and unrestricted API access prevent the current mod from using Noita's supported Workshop route.

Report a problem

In the app, open Settings & help and select Export safe diagnostic report… under About Noita Together 2 - Beta. Share the report with the person who invited you to the beta. Include the release version, game build, error text, whether you use Steam or GOG, and steps to reproduce. Review the export before sharing; never post tokens, credentials, saves or private pairing files. Project source: Noita Together 2 on GitHub. Check the project for current reporting options; share beta reports with your beta contact.

Beta limits

Windows x64 companion only; game-native components may be x86. One companion and one game per PC. Steam/GOG and clean Windows first-run, real multiplayer recovery and beta-update cases still require owner testing.
