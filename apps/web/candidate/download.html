Getting started

  1. Download the ZIP and extract all files to a writable folder.
  2. Run NoitaTogether2.exe and sign in with Twitch or Google.
  3. Keep Noita closed. Choose its installation folder in the app, then install or repair the matching local mod.
  4. Launch Noita, enable Noita Together 2 - Beta and its required native/API permission. Choose a lobby in the app, select New Game in Noita, and wait for the host to Start.

Before you join

Windows x64 portable beta; one app and one game per PC. Steam and GOG use the app-managed local mod. Workshop installation is unavailable for this native mod. Linux/Proton, a full installer and automatic updates are outside this beta.

Unsigned builds can trigger Windows reputation prompts. Check the download source and published checksum before deciding whether to run a build. Small invited testing comes first; large-lobby capacity is not certified.
