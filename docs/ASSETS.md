# Source and asset provenance

Original Noita Together source/artwork is reused and adapted under the preserved upstream MIT notice, copyright 2022 Soler91. This includes loot helpers, shared pickup/world-rule hooks, player-list/biome mappings and UI assets. New NT2 desktop/native work retains its own component MIT notices. The app icon is original font-free NT2 geometric artwork, reproducible from `apps/desktop/tools/generate-beta-icon.py` and `apps/desktop/src-tauri/icons/beta-icon.svg`.

Game-derived content is distinct from original mod authorship. Noita's installed `tools_modding/Noita-ModdingAgreement-v100.rtf` permits specified non-commercial mods for paid Noita while retaining Nolla's game rights and limiting substantial-content redistribution. Do not interpret the legacy repository's MIT licence as relicensing game pixels or permitting redistribution of game binaries/data. References such as `data/enemies_gfx/player.xml` are runtime references to the player's game, not bundled copies of those files.

Immediate legacy origin is established for the mod artwork. Earlier derivation of bundled player/emote sheets, biome thumbnails and certain perk/Sampo/hourglass/wand-stat icons is not independently documented as original NT2 artwork. Treat game-derived portions under the applicable game modding terms; do not claim a separate unrestricted art licence. The relevant groups are `mod/noita_together2/files/g3/emotes/player*.png` and `emotes_gfx_player*.png`, `files/g3/ui/biomes/*.png`, `files/c1/items_gfx/banned_perks/glass_cannon.png`, `files/c2/entities/sampo/disabled_sampo.png`, `files/c2/ui_gfx/status_indicators/nt_hourglass_*.png`, and `files/g3/ui/item_bank/icon_*.png`. This is not a blanket defect finding for all legacy MIT images or path-adapted XML.

No game executable, object file, original game DLL, data.wak or extracted game directory is a source-export input. Catalogue identifiers/resource paths are metadata, not a bundled game. Regeneration tools may read an explicitly supplied paid local game archive; they must not export the archive or game assets.
