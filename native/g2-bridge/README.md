# G2 native bridge

First-party project source; Windows/x86 Noita ABI with an x64 Rust/Tauri owner. Uses Windows SDK APIs and static MSVC runtime. No third-party bridge, game executable/runtime replacement, hooks or proprietary game files are distributed. Project release licensing/signing remains a release-gate responsibility; this is a local source-built development candidate.

Build: native/g2-bridge/build.ps1 with VS2022 Community x86 tools. Output is ignored spikes/noita-entry/.build/g2-bridge/nt2_g2_bridge.dll. Build publishes apps/desktop/g2-native-profile.json with game/originalLua/mod/bridge hashes. It does not edit the accepted G1 profile. The desktop build embeds this candidate; package-g2.ps1 exports the installer and server-owned-profile input for joint review.

ABI exports use __cdecl: nt2_g2_prepare(uint32_t*,uint8_t[16]), nt2_g2_seed_accepted(const uint8_t[16],uint32_t actual), nt2_g2_world_loaded(const uint8_t[16]), nt2_g2_status(const uint8_t[16]), nt2_g2_close(const uint8_t[16]). The lifetime finalizer captures the immutable token. Prepare returns1 with a seed,0 unavailable,-2 saved-world refusal. Status returns0 unavailable,1 protected hold,2 authoritative release. The game thread alone calls game APIs; a pinned worker does only bounded local IPC every2s and is joined on qualified close/replacement.

The fixed same-SID local pipe prefix is nt2-g2-v1-.32-byte messages: little-endian magic0x3247544e, ABI2, operation, payload,16-byte nonce. Operations1 prepare,2 Continue refusal,3 actual seed,4 protected player loaded,5 heartbeat/state,6 context close. Successful replies echo the nonce; payload returns seed for prepare and hold/release for other acknowledgements. Rust validates the current owner PID/token/generation and binds the pending record to the authoritative service/desktop/room/run/epoch/configuration. A durable create-new marker commits consumption before grant; this deliberately refuses uncertain crash/reply-loss replay.

A fixed public LOCALAPPDATA/NoitaTogether2/bridge-app.txt contains only the current Rust app image path, permitting the same source build to move between computers. It does not carry credentials and does not establish anti-cheat or protection from arbitrary same-user malware. Game installation paths are validated by Rust and installer before arming; original Lua and saves are never copied/replaced. No remote scripts are accepted.

Native checks: apps/desktop/tools/test-native-g2.ps1 compiles an isolated test DLL with a different pipe prefix and save-check bypass, then runs production bridge/mod source using the owner's original LuaJIT DLL and stubbed game APIs. Production build never enables these test macros. The native worker/state/finalizer behavior is real; protection and engine lifecycle acceptance require the two actual Noita tests in apps/desktop/G2-test-steps.md.
